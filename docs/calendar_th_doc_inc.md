Contains exchange-business calendar utility functions:

- [**calendarGen**](azapy.MkT.MkTcalendar.calendarGen) : generate an exchange-business calendar
- [**NYSEgen**](azapy.MkT.MkTcalendar.NYSEgen) : generate NYSE business calendar (scheduled for deprecation)
- [**gen_calendar_names**](azapy.MkT.MkTcalendar.get_calendar_names) : generate a list of valid exchange-business calendar names
